# 引擎組裝站｜場域模型

車廠引擎組裝站（引擎腳與變速箱組裝）的 3D 數位孿生，作為 AI 防錯 PoC 的場域基礎。
純前端（Three.js，透過 CDN 載入），不需要建置步驟。

## 本機執行

```bash
python3 -m http.server 8794
```

打開 http://localhost:8794 。因為使用 ES module，不能直接雙擊 `index.html`。

## 目前包含

- 兩側作業高台、欄杆、工具桌／層板、三色燈、前方門型吊架
- 車輛（引擎室開啟）、引擎與變速箱、自動升降承盤
- 左右作業員（身高 1.75 m）與懸吊鎖附工具
- 三支攝影機 LEFT UP／RIGHT UP／RIGHT：位置由訪綱的距離、高度、角度推算，含視錐與即時子畫面
- 四個螺絲孔位與順序：步驟 1 左下、右下 → 步驟 2 承盤下降 → 步驟 3 左上、右上（團隊現場紀錄；左右以車輛本身為準）
- 散熱器（車頭地標）與「螺絲孔位特寫」視角
- 產線滑軌與車體載具，點選可看滑軌造成的限制
- 3 分鐘標準作業循環與流程條：1 鎖下方螺絲 → 檢查點 → 2 承盤下降 → 3 鎖上方螺絲
- 子畫面標註框：3D 物件投影成 2D 框，示範之後產生 YOLO 合成訓練資料的格式
- 「匯出場域 JSON」：攝影機內外參數、ROI 世界座標、時間軸

## 座標系

- 單位公尺，Y 向上
- 車頭朝 +Z，+X 是車輛左側（站在車頭前面向車輛時的右手邊）
- 地板（產線坑道底）y = 0，高台面 y = 1.42

## 參數

全部集中在 [`js/params.js`](js/params.js)，每一項都標註來源與狀態：

| 狀態 | 意思 |
|---|---|
| `confirmed` | 訪綱中業主直接回答 |
| `derived` | 由已確認數值推算 |
| `assumed` | 合理假設，待補充 |

補充新參數時只要改 `params.js`，場景與參數表會一起更新。

### 主要假設（待確認）

1. **攝影機角度**：訪綱的 77°／97°／114° 解讀為俯視方位角，從車輛左側（+X）量起，90° 代表正對車頭。這個解讀和訪綱平面示意圖的三條視線方向一致。
2. **觀測距離**：視為攝影機到目標的直線距離，水平距離由距離與垂直高度推算。
3. **螺絲孔位座標**：順序已由團隊現場確認，實際座標待實測，改 `ZONES`。
4. **高台寬度、車長、引擎室開口高度、攝影機視角**：目前為假設值。
5. **滑軌移動速度**：未知，目前車輛不移動。
