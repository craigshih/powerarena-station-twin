    偵測管線（依業主實際做法）

    1. YOLO 偵測全畫面找出鎖附工具、作業員、承盤，建立 Anchor。用 YOLO11 微調小模型，可在邊緣裝置即時推論。
    2. Anchor ＋ Linear Regression 追蹤之後只在 Anchor 周圍搜尋，用迴歸算出平滑位移；偏移超過門檻或定期才重新以 YOLO 校正。軌跡不抖、不易認錯相似物件、較能抵抗遮蔽。
    3. 工具框 ∩ ROI螺絲太小又常被遮住，改判斷「工具與指定區域重疊」。
    4. A → B → C 狀態機B（承盤下降）未來可改用 IoT 訊號取得精準時間點，視覺只需判斷工具是否在 B 之前進入 C 區。

    要抓的三種異常

    • 降前鎖附：在承盤下降前就做第二階段（最關鍵）
    • 超過鎖附時間：第一階段沒在檢查點前 2 秒完成
    • 錯誤步驟：沒依 SOP 順序

    為何不用 YOLO-World

    業主表示企業普遍不願提供資料，開放詞彙模型在這種場域跑不出成果，所以採用可微調的小模型。
